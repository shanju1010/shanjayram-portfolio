# Shanjayram Portfolio V3.6 — Editorial Motion

An original React + TypeScript + Vite portfolio inspired by cinematic editorial portfolio design. No source code or assets from the Elena Voss template are copied.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (typically http://localhost:5173).

## Production check

```bash
npm run build
npm run preview
```

## Features

- Oversized editorial hero and responsive typographic system
- Scroll progress and reveal animations
- Sticky stacking project cards on desktop; accessible linear cards on mobile
- Animated marquee and scroll-responsive hero composition
- Accessible case-study drawer with Escape, focus trapping and body scroll lock
- Reduced-motion support and mobile navigation
- Project source links only where public links are known
